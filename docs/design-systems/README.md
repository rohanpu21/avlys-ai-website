## Future portfolio image work

Read the relevant originals before composing prompts. Choose the system suited to the client's product instead of combining every palette. Retain Avlys's white, blue, and charcoal identity; no global rebrand is implied. Use concrete project workflows, purposeful typography, realistic product layouts, and generous safe margins. Avoid generic AI imagery, decorative node networks, invented performance metrics, testimonials, contact details, and unsupported production claims.

Portfolio cards use client/product illustrations in `coverImage`. Architecture diagrams belong in `architectureImage` and appear only inside the project detail page. Preserve existing good covers. Generated UI concepts must remain labeled as illustrations rather than verified screenshots.
