# Avlys Data: AI-search discovery and inquiry improvements

Implementation date: 2 October 2026. Website and pre-push validation notes; no live-deployment or search-ranking claims.

## Scope and design

- Restored the existing GatewayFlow animated data hero and blue aura; retained Geist Sans and the approved white/blue/charcoal glass design. The existing animation pauses offscreen/in background tabs and respects reduced-motion preferences.
- Added `/data/image`, `/data/audio` and `/data/video`, linked from the main catalogue. All collection descriptions are rendered in initial HTML on their category page. The existing interactive main catalogue is retained.
- Added category-specific task guidance, buyer requirements, FAQs, titles, descriptions and canonicals. Text/document work and human egocentric capture remain separately scoped rather than presented as ready inventory.
- Reused one DatasetCard component across the interactive catalogue and server-rendered pages to avoid drift.
- Added visible breadcrumbs, Service/WebPage or CollectionPage/BreadcrumbList/FAQPage JSON-LD connected to the existing Avlys organization. FAQ answers use the same records as the visible content. No fake Dataset ownership, prices, ratings or stock claims.
- Added a prominent sample-and-pricing CTA and direct WhatsApp/call options. Existing data-brief submission still prepares an email; it does not claim to send a message or store a lead.
- Added category sitemap entries and actual content-update dates. Updated the existing supplemental `llms.txt` with data-service links and scope, without treating that file as a ranking mechanism.
- Preserved existing OAI-SearchBot access and existing training-crawler preferences. Kept source/rights research records internally and the existing short public source note.

## Primary guidance consulted

- [OpenAI crawler documentation](https://developers.openai.com/api/docs/bots): OAI-SearchBot supports search discoverability. GPTBot is a separate training crawler; ChatGPT-User handles user-initiated fetches. Robots access and hosting/firewall access both matter.
- [Google: AI features and your website](https://developers.google.com/search/docs/appearance/ai-features): normal crawlability, textual content, internal links and accurate structured data remain relevant. There is no special AI schema or machine-readable file required for inclusion, and indexing/serving are not guaranteed.
- Local installed Next.js documentation: JSON-LD, async dynamic-route parameters, sitemap metadata and Link component. The installed framework is Next.js 16.2.4.

The practical inference is to make the actual service and each collection type readable at stable URLs, and connect those pages to a specific inquiry path. These changes cannot establish that ChatGPT already recommends Avlys.
