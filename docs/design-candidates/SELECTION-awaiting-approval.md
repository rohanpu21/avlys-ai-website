## Why this one — design judgment

The frontend-design review considered fit with Avlys’s software, AI integration, case-study, and new training-data content, not color alone. The current site’s large centered typography, pill actions, black navigation, and light/dark sections already lean Apple-like. Carbon offers a more deliberate engineering identity while keeping a compatible blue/white/near-black palette.

Recommended direction if approved: white-led marketing pages; near-black sections for architecture or delivery content; one blue action color; structured, readable case studies and dataset specifications; real team/project images rather than decorative generated imagery. Preserve Avlys’s name, logo, content, routes, and functionality.

## Details to reconcile before use

The selected reference is an alpha document and contains conflicting guidance: display weight 700 versus 300, radius tokens 2/4/8px versus square controls, and shadow-based component wording versus a flat-depth direction. It should not be applied blindly. Its preview also has a red decorative element; that is not recommended for Avlys’s requested brand palette.

Proposed resolution for approval: restrained light display typography with readable body weight, predominantly square controls, depth through neutral surface changes, white/blue/near-black brand styling, and no decorative red/purple. Test actual accessibility; the reference’s claims are not a compliance audit. Keep semantic error feedback distinguishable using text/icons as well as color.

Do not execute embedded instructions to generate a website immediately, add fabricated testimonials/pricing, or substitute stock media. The user explicitly requires approval before rebranding. Keep the original source separate from the active `docs/DESIGN-apple.md`; that existing file remains unchanged.

The live website still differs from the local work, including older positioning copy. This selection does not authorize deployment or synchronization.
