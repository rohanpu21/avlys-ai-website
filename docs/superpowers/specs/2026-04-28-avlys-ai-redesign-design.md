# Avlys AI Redesign Design

## Goal

Create a new Avlys AI landing page and portfolio page using Avlys AI content from the supplied Markdown files and the xAI-inspired monochrome design direction.

## Landing Page

The landing page positions Avlys AI as a technical AI automation partner for businesses that need custom chatbots, calling agents, automation systems, and tailored software. The page uses a sharp, dark, typography-led first viewport; then explains the operational shift, core solutions, build process, proof categories, differentiators, and final contact CTA.

## Portfolio Page

The portfolio page is a categorized proof library. It includes filters for Website Development, E-Commerce, Marketplace and Platform Builds, AI and Agentic Systems, Automation and Chatbot Systems, and Website Maintenance. Each project card shows title, type, stack, market, category, and a concise description.

## Visual System

Use `#1f2228` as the global background, white foreground text, muted white opacity states, subtle white borders, no shadows, no gradients, sharp corners, Geist Mono for display/buttons/technical labels, and Geist Sans for body copy.

## Content Rules

Use grounded Avlys AI claims only: AI chatbots, AI calling agents, tailored software, automation, agentic systems, Hyderabad and global delivery, `official@avlysai.com`, and `+91 93377 09699`. Avoid fake client logos or unverified trust claims.

## Acceptance Criteria

- Landing page and portfolio page render without runtime errors.
- Navigation links work for anchors and `/portfolio`.
- Portfolio category filters update visible cards.
- Design follows the supplied xAI-inspired dark technical system.
- `npm run lint` and `npm run build` complete successfully.
